# Schema Contract Map

This document defines the cross-layer contract parity for the AI Wall Street benchmark platform. It maps the Supabase database schema to the Python engine models and frontend TypeScript consumers.

## Core Truth Chain Tables

### 1. Decisions (`decisions`)
Stores trading decisions generated by LLMs with source attribution.

| Column | DB Type | Python Type | TS Type | Nullable | Source of Truth |
|--------|---------|-------------|---------|----------|-----------------|
| `id` | `UUID` | `str` | `string` | No | DB |
| `source_id` | `TEXT` | `str` | `string` | No | Engine (News) |
| `ticker` | `TEXT` | `str` | `string` | No | Engine (LLM) |
| `signal` | `TEXT` | `Literal["BUY", "SELL", "HOLD"]` | `string` | No | Engine (LLM) |
| `confidence` | `INTEGER` | `int` | `number` | No | Engine (LLM) |
| `reasoning` | `TEXT` | `str` | `string` | No | Engine (LLM) |
| `model_provider`| `TEXT` | `str` | `string` | No | Engine (Config) |
| `model_name` | `TEXT` | `str` | `string` | No | Engine (Config) |
| `status` | `TEXT` | `str` (Enum-like) | `string` | Yes | Engine (Validation) |
| `metadata` | `JSONB` | `dict` | `any` | Yes | Engine (Mixed) |
| `trade_id` | `UUID` | `str` | `string` | Yes | Engine (Execution) |
| `created_at` | `TIMESTAMPTZ` | `datetime` | `string` | Yes | DB |

**High-Risk Metadata Fields:**
- `strategy_reasoning`
- `verification_reasoning`

## High-Risk Fields Requiring Special Validation

| Field | Risk Factor | Validation Strategy |
|-------|-------------|---------------------|
| `decisions.signal` | Case sensitivity drift | Enum enforcement in Pydantic & TS |
| `decisions.metadata`| Silent key renaming | Pydantic sub-model validation |
| `trades.price` | Decimal precision loss | Numeric(20,4) enforcement |
| `llm_reasoning_logs.prompt` | Tool call serialization | Normalized transcript schema |
| `memories.memory_type` | Unrecognized types | Strict Literal typing |

## Attribution Chain Invariants

1. **Trade → Decision**: Every trade must link to exactly one decision via `decision_id`.
2. **Decision → Source**: Every decision must have a valid `source_id` matching a `newsletter_snapshots.source_id`.
3. **Lesson → Trade**: Every `LESSON_LEARNED` memory must include a `trade_id` in its metadata.
4. **Tool Integrity**: Every decision with `signal` in ['BUY', 'SELL'] MUST have corresponding tool call entries in the associated `llm_reasoning_logs`.
