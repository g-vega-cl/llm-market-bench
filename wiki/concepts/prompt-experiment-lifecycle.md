# Prompt Experiment Lifecycle

Every prompt mutation in the daily predictor and backtest autoresearch flows moves through a
well-defined lifecycle. The key invariant is that an experiment's `metrics` are only populated
once its predictions have actually been evaluated — a freshly deployed variant carries
`metrics = NULL` until its evaluation window closes.

## States

1. **Active / awaiting evaluation** — a newly mutated prompt variant is deployed with
   `status = 'active'` and `metrics = NULL`. It has not yet accumulated evaluated predictions,
   so no ratchet score exists.
2. **Evaluated / saved** — once the week's predictions are scored, the experiment's `metrics`
   are written and its `status` becomes `'saved'`. This is the parent that the next mutation
   ratchets from.

## Ratchet Flow

When a backtest week completes, the flow is:

1. The **parent** (currently active) experiment is updated in place with the completed week's
   metrics and `status = 'saved'` — both in SQLite and synced to Supabase.
2. A **new** variant is generated by the meta-researcher and inserted as `status = 'active'`
   with `metrics = NULL`, `parent_tag` pointing at the just-evaluated parent, and a
   `change_description` of the form `Backtest mutation week N from parent score X`.

This ordering means the parent always carries a real score while the child is explicitly
marked as pending, avoiding the previous behavior where a new variant inherited the parent's
score before it had been evaluated.

## UI Representation

- `resolveRatchetMetrics` only computes metrics from predictions whose `prompt_variant_tag`
  **strictly matches** the experiment's `variant_tag`. It no longer falls back to unrelated
  evaluated predictions, so a new variant cannot borrow another variant's score.
- When an experiment is `active` with no resolvable metrics, `DailyScoreBreakdown` renders the
  **"Live Variant Evaluation In Progress"** placeholder (with an ACTIVE badge) instead of a
  score breakdown or formula substitution.
- The autoresearch milestone cards show `Pending` for the active score and
  `Pending Evaluation` for the delta when the active experiment is still evaluating, rather
  than `N/A` or a stale delta.
