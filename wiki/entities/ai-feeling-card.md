# AI Feeling Card

The `AIFeelingCard` component renders the "How is the AI Feeling?" section on the Today dashboard. It displays the latest market sentiment analysis from the `market_feelings` table — sentiment label, emoji, direction badge, confidence bar, why-explanation, primary concern, buy/sell trade split, last-analyzed timestamp, and model name — all in a single card.

## Data Sources

The component consumes data already present on the `TodayData` type:
- `marketFeeling` — the latest `MarketFeeling` row (with optional `formattedTime`)
- `trades` — today's trades with `portfolios.owner_id` for owner attribution
- `isSentimentStale` — boolean flag indicating data is older than 4 hours

No additional fetching is required; the data is passed from the parent `TodayPage`.

## LLM-Only Trade Attribution

The buy/sell split counts **only autonomous LLM trades**. Before counting, the component filters out mechanical system portfolios using `isSystemPortfolio(t.portfolios?.owner_id)` (imported from `~/features/portfolios/lib/config`), so `sys-*` strategies (e.g. `sys-pead-drift`, `sys-max-pain`) never inflate the AI buy/sell counts. The same exclusion is applied in `TodayStatusBar` so the sticky status bar and the feeling card agree.

## Layout & Boxel Styling

The card follows the Matcha & Cedar boxel design system (see [[entities/design-system]]):

- The outer `<section>` is `flex flex-col gap-4 h-full` so it stretches to match sibling cards in the Today page's `items-stretch` Row 2 grid.
- The `Card` uses `isHoverable`, `padding="md"`, and `h-full flex flex-col justify-between gap-4`, with the footer pinned to the bottom via `mt-auto`.
- The previous gradient background accent overlay has been removed in favor of the flat boxel surface.

## Sub-Components

To keep cognitive complexity ≤ 15 (Biome rule), the card is split into three internal sub-components:

- **`SentimentHeader`** — Renders the emoji at `text-xl` (no float animation), the sentiment label at `text-lg font-bold` with direction-based color (`text-success` for BULLISH, `text-danger` for BEARISH), and a direction `Badge`. When `isSentimentStale` and a feeling exists, it renders a `Badge colorScheme="warning" variant="outline" size="xs"` reading `STALE` (replacing the old amber pill).
- **`TradeSplit`** — A 2-column grid of recessed `voxel-trough rounded-none p-2.5` tiles showing buy/sell counts (`text-sm font-bold font-mono text-success` / `text-danger`) with `text-xs font-normal text-boxel-muted` labels. Only renders when `totalTrades > 0` (after the `sys-*` exclusion).
- **`CardFooter`** — Renders the last-analyzed timestamp (or "Waiting for analysis..." fallback) and model name in `text-xs font-normal font-mono text-boxel-muted`, plus a `text-sm font-bold text-accent uppercase tracking-wider` link reading `View full market analysis →` to `/market-overview`.

The confidence bar is accompanied by a `text-xs font-normal text-boxel-muted` caption: "Self-assessed conviction score generated by the AI meta-analyst." The primary concern renders as a `Badge colorScheme="neutral" size="xs"`.

## Color Scheme Helpers

Three utility functions map data to design-system color schemes:
- `getDirectionColor(direction)` — returns Tailwind text color class
- `getDirectionColorScheme(direction)` — returns `ColorScheme` for `Badge` component
- `getConfidenceColorScheme(score)` — returns `ColorScheme` for `ConfidenceBar` (≥70 success, ≥40 warning, <40 danger)

## Empty State

When `marketFeeling` is `null`, the card renders:
- Sentiment label: "Analyzing..."
- Emoji: "🤔"
- Timestamp: "Waiting for analysis..."
- No STALE warning (even if `isSentimentStale` is `true`)
- No trade split, no confidence bar, no why-explanation, no primary concern
