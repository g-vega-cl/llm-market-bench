# Fetch Daily Newsletter Tool

Canonical `fetch_daily_newsletter` tool in `core/llm/tools.py` for trading LLMs (OpenAI, Claude, Gemini).

## Purpose

Provides a standardized way for trading LLMs to fetch the daily newsletter, ensuring consistent data access across different model providers.

## Usage

- Available to OpenAI, Claude, and Gemini trading agents
- Defined in `core/llm/tools.py`
