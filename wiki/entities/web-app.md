# Web App

TanStack Start dashboard in `apps/web` providing real-time portfolio telemetry, trade audit trails, and LLM cognitive synthesis. The frontend is organized into vertical feature slices and styled with the Matcha & Cedar Voxel design system.

## Primary topbar routes

The global navigation bar in `apps/web/src/routes/__root.tsx` exposes strictly 3 top-level destinations:

- **B** (`/`): The home destination is rendered as a compact `B` logo button (`font-mono`, `h-9 w-9`) carrying `aria-label="Home"`. `/` is a single-screen call to action (`apps/web/src/features/home/pages/HomeCtaPage.tsx`) built on the design-system `SceneStage` primitive (`variant="hero"`, `motionRole="reactive"`): an eyebrow, the headline "Build your own trading bot.", a concise 1-sentence subheadline, and an open-sky 3-CTA stack (`data-testid="home-cta-actions"`, no enclosing card plaque or trust-bullet strip): one accent CTA into `/lab` (`Start building`), a secondary `Take the investing style test` button into `/personality` (`data-testid="take-personality-test"`), and a tertiary underlined link (`See how the published bots are doing` with `.home-hero-copy` text-shadow) into `/leaderboard`. The route loader resolves the US Eastern market session atmosphere (`resolveAtmospherePhase(new Date(), 'market-et')`) server-side so SSR and CSR agree on first byte without flashes or CLS, and exposes accessible foreground HUD controls in the `SceneStage` `controls` slot via `SceneHudControls`: an atmosphere switcher (`Sky: <Phase>`, `data-testid="atmosphere-switcher"`) that cycles all four phases and a Pause/Play motion toggle. Behind it sits `GardenBackdrop.tsx` (backed by `voxel-world.ts`, `worlds.ts`, `worlds/cedar-sanctuary.ts`, `worlds/shared-terrain.ts`, `garden-renderer.ts`, and `garden-scene.ts`) — the panoramic **Cedar Sanctuary** floating voxel ridge across the dynamic Matcha & Cedar atmospheres with 4-plane depth parallax (sky + zenith particles, far cloud sprites drifting outward from the central open-sky corridor, wide cedar highland ridge, near cloud sprites), portrait-mobile vertical framing (`originY` shifting toward `0.82 * H` on narrow viewports so CTAs stay above the trees via `computeCedarFraming`), an intentional 1.1s stepped upward entrance reveal over the single `sortKey`-sorted `island` canvas, extended top atmospheric sky vignettes maintaining AAA open-sky copy contrast, and calm micro-life (fireflies, brook ripples, lantern halos, drifting haze wisps, autumn leaves, sky motes). Face extraction (`extractWorldFaces`) is cached once per session via `getCedarWorldAndFaces()`, offscreen layers (sky, foot, island, lantern sprite, and one cropped canvas per cloud) are built by `buildCedarScene()` once per mount/resize/atmosphere change and disposed on rebuild, and the 30fps-capped rAF loop stops on idle, on `document.hidden`, and for `prefers-reduced-motion` users. `.home-hero-viewport` and `.scene-stage-hero.home-hero-viewport` in `apps/web/src/styles/app.css` fit the hero cleanly below the sticky navbar. See [[entities/recipe-studio]], [[concepts/living-scene-backdrops]], and [[concepts/cumulative-layout-shift]].
- **Recipes** (`/recipes`): Rendered as a list/scroll SVG icon (`h-9 w-9`) with `aria-label="Recipes"`. The route is public: anonymous visitors get the template gallery, signed-in users get the **My Bots dashboard**. Portfolios is no longer a topbar item; it is reached from the `/lab` "Audits, Benchmarks & Retired Archives" block (`/portfolios`, a 3-block capital allocation arena in `apps/web/src/features/portfolios/pages/PortfoliosPage.tsx`). Block 1 renders the interactive `PortfolioComparisonChart` with timeframe and benchmark controls. Block 2 renders **Active LLM Agents** using single-level Voxel cards. Block 3 renders **Systematic Strategies** (`sys-*`) in a dedicated section.
- **Lab** (`/lab`): Rendered as a conical flask SVG icon (`h-9 w-9`) with `aria-label="Lab"`. 3-block experimental directory (`apps/web/src/routes/lab.tsx`) indexing all specialized research, telemetry, and audit routes with descriptions, linking to **Retired Agents** (`/retired-agents`, `apps/web/src/routes/retired-agents.tsx`), a dedicated page for frozen historical portfolios. The top of `/lab` no longer mounts the chat builder; the builder lives at `/build` and is linked from the homepage and gallery.

The topbar is a single non-wrapping row (`flex items-center`, no `flex-wrap`). The left cluster holds the `B` logo and the three nav items; the right cluster (`ml-auto shrink-0`) holds only the login/logout control. The authenticated user's email is **not** rendered in the navbar — the email badge that previously linked to `/profile` has been removed, so the logout link stays on the same row regardless of email length.

## Specialized lab routes

- **Recipe Builder** (`/build`): Conversational strategy compiler (`apps/web/src/features/recipes/builder/`). Describe a bot in plain English, get a validated Push v2 recipe, then backtest or go live. The primary entry point for creating new strategies.
- **My Bots Dashboard** (`/recipes`): Signed-in users see their saved strategies with live controls, backtest history, and alerts. Anonymous visitors see the read-only template gallery.
- **Investing Style Diagnostic** (`/personality`): 16-question investing-personality quiz in four acts (`apps/web/src/features/personality/`) that scores Horizon, Signal Anchor, Crowd Stance, and Execution Tempo into a four-letter type code, matches the visitor to one of 16 archetypes, and recommends the mapped starter recipe with a `Build this bot` link into `/build?idea=`. Shareable results live at `/personality/t/<CODE>`; legacy `?archetype=<id>` links normalise to it. See [[entities/personality-quiz]].
- **Live Recipe Backtest** (`/recipes/backtest/$jobId`): Day-by-day streaming view of a running backtest (`apps/web/src/features/recipes/pages/RecipeBacktestPage.tsx`). The route loader calls `fetchRecipeRunDetailFn` (failing soft to `null`) and the page polls every 1.5s while the job is `pending`/`processing`. The page renders the simulation timeline (`#simulation-timeline`, day tiles + a compact `SelectedSlotBar` with a `Jump to Trace ↓` anchor), developing telemetry (metric tiles + equity progression with a Midpoint/Net P&L toggle), the current portfolio & open positions, executed/skipped trades, and a `BacktestSessionTraceBlock` (`#session-trace`) below the trades with `‹ Prev` / `Next ›` session stepping and an `↑ Timeline` anchor back to the timeline. A `live_turn` job opened here renders an `Incompatible Job Mode` error card. See [[entities/recipe-studio]].
- **Autoresearch Arena** (`/autoresearch`): Renders the Unified Risk-Adjusted Z-Score with $\sigma$ unit suffix, baseline comparisons, and step-by-step arithmetic drawers (`ScoreBreakdown.tsx`, `ScoreCalculation.tsx`, see [[concepts/risk-adjusted-z-score]]).
- **Daily Predictions** (`/daily-predictions`): Independent model tabs with strict track isolation and 4-pillar composite ratchet scores. See [[entities/daily-market-predictor]].
- **Portfolio Detail Pages** (`/portfolios/:id` and `/renko`): Real-time portfolio analysis, performance charts, current positions, and recent trades audit trail in Eastern Time (`ET`).
- **Retired Agents** (`/retired-agents`): Dedicated archive page (`apps/web/src/routes/retired-agents.tsx`) listing every frozen, inactive portfolio (`!p.is_active`) with its owner name and total equity, each linking to its `/portfolios/$portfolioId` detail page. It replaces the former inline **Retired Agent Archive** table that lived inside the `/lab` Audits block. The route loader calls `fetchPortfolios()` via a `createServerFn` and filters to inactive portfolios; the `RetiredAgentsView` component renders an empty state ("No retired agents.") when none exist. The `/lab` directory links to it from the "Audits, Benchmarks & Retired Archives" category.
- **Companies** (`/companies`, `/companies/$ticker`): Institutional company & sector research dossier explorer (`apps/web/src/features/companies/`). The directory (`CompaniesPage.tsx`, `fetch-companies.ts`) supports search by ticker/name/sector, verdict filter pills, and equal-height summary cards (verdict + conviction, spot price, mention count). The dossier page (`CompanyDossierPage.tsx`, `fetch-company-dossier.ts`) renders a verdict banner, economic moat / valuation / options cards, a thesis falsification panel, full Markdown analysis via `MarkdownContent`, and a historical research timeline. It is reachable from `/lab` and from `/generated-newsletters` ("Explore Company Dossiers →"). See [[entities/company-research-reports]].
- **Investment Chat Gateway** (`/chat`): Conversational research interface with live database query tools and memory search. See [[entities/investment-chat-gateway]].
- **AI Memories Page** (`/memories`): Searchable archive of market consensus events, economic calendar catalysts, lessons, and resolved trades. See [[concepts/memory-feedback]].

## Private routes

- **LLM Proxy Logs** (`/llm-logs`): Owner-only viewer for the free LLM proxy audit trail (`apps/web/src/routes/llm-logs.tsx`, `apps/web/src/features/llm-logs/`). `beforeLoad` redirects an anonymous visitor to `/auth` with `/llm-logs` as the return path, the component renders `<NotFound />` for a signed-in user outside the `isAllowedLlmLogsEmail` allowlist, and `fetchLlmLogsFn` re-checks the caller server-side. The route head declares `robots: noindex, nofollow`, and the page is not linked from `/lab`. See [[entities/llm-logs]].

## Architecture

- Built with TanStack Start and React Router v7 SSR.
- Uses TanStack Query for data fetching with SSR-safe QueryClient.
- The homepage (`/`) renders `HomeCtaPage` on `SceneStage` (`variant="hero"`, `motionRole="reactive"`). Its route loader (`apps/web/src/routes/index.tsx`) resolves the US Eastern market session atmosphere server-side so SSR and CSR match without a sky flash, and exposes foreground HUD controls (`Sky:` atmosphere switcher and Pause/Play motion toggle). The panoramic Cedar Sanctuary backdrop (`apps/web/src/features/home/backdrop/GardenBackdrop.tsx`, geometry in `voxel-world.ts` / `worlds.ts` / `worlds/cedar-sanctuary.ts` / `worlds/shared-terrain.ts`, offscreen baking helpers in `garden-renderer.ts`) caches voxel face extraction once per session, bakes offscreen layers per viewport size and atmosphere phase, disposes superseded canvases, and animates at a 30fps cap via a single rAF that stops on idle, on `document.hidden`, and for `prefers-reduced-motion` users. See [[concepts/living-scene-backdrops]] and [[concepts/cumulative-layout-shift]].
- Root route (`apps/web/src/routes/__root.tsx`) installs `useIdleRouteWarmup()`, which delegates to `warmRouteChunks(router, signal)` in `apps/web/src/utils/route-warmup.ts` inside a `requestIdleCallback` (with a `setTimeout` fallback). It resolves every path in `PRELOAD_WARMUP_ROUTES` (`/`, `/portfolios`, `/lab`, `/recipes-demo`, `/recipes`, `/profile`, `/leaderboard`, `/companies`, `/how-it-works`, `/audits`, `/autoresearch`, `/autoresearch-backtest`, `/daily-predictions`, `/daily-predictions-backtest`, `/ai-predictions`, `/market-overview`, `/reasoning`, `/memories`, `/concepts`, `/cause-and-effect`, `/generated-newsletters`, `/earnings-audit`, `/barometer-audit`, `/renko`, `/retired-agents`, `/chat`, `/login`, `/signup`) plus `DYNAMIC_WARMUP_SAMPLE_PATHS` (`/portfolios/_`, `/companies/_`, `/recipes/backtest/_`, `/memories/chain/_`) through `router.getMatchedRoutes()` and calls `router.loadRouteChunk()` — never `preloadRoute()` — so route JS chunks are compiled into the browser module cache without executing `loader` or `beforeLoad` handlers. It skips warmup when `navigator.connection.saveData` is set, respects `route.options.preload === false`, yields between chunks via `requestIdleCallback`, and aborts cleanly on unmount via an `AbortController`. See [[concepts/chunk-reload-recovery]].
- Route-level errors are handled by `DefaultCatchBoundary` (`apps/web/src/components/ui/DefaultCatchBoundary.tsx`). Non-chunk errors render the design system `ErrorComponent` with `Try Again` / `Back` / `Home` actions. Dynamic chunk failures (`isDynamicChunkError`) instead render `ChunkRecoveryView` (`Checking application update…` → `Updating application to latest version…` → `Unable to load the latest application update. Please reload the page.` with a `Reload Page` button), claim a single reload slot via `claimChunkReloadAttempt()`, and report telemetry to PostHog (`captureException` with `source`, `is_root`, `pathname`, `route_id`, plus `chunk_error: true` and `auto_reloaded`) before dispatching `reloadAtTarget(targetHref)`. Reporting and dispatch are deferred by one macrotask so the parent `PostHogProvider` `init()` completes on cold root errors. See [[concepts/chunk-reload-recovery]].
- Hashed build assets under `/assets/*` are served with `Cache-Control: public, max-age=31536000, immutable` and `X-Content-Type-Options: nosniff` in both `apps/web/netlify.toml` (`headers` table) and `apps/web/public/_headers`, so previously fetched chunks are revalidated never and served from proxy/browser caches.
- Netlify deploys (`apps/web/netlify.toml`) use a fail-safe `[build] ignore` exclude-list (`git diff --quiet $CACHED_COMMIT_REF $COMMIT_REF -- . ':!ROADMAP.md' ':!wiki/' ':!apps/engine/' ':!apps/free_llm_proxy/' ':!.github/' ':!docker/' ':!supabase/' ':!.agents/' ':!GEMINI.md' ':!AGENTS.md' ':!README.md' ':!git-history/' ':!knowledge-db/' ':!raw/'`) guarded by `[ -n "$CACHED_COMMIT_REF" ] && [ "$CACHED_COMMIT_REF" != "$COMMIT_REF" ]`, so backend-only and docs-only commits skip Netlify builds while mixed commits, new workspace packages, empty caches, and manual UI redeploys still build. Verified hermetically by `apps/web/src/test/netlify-config.test.ts`.
- Styled with Tailwind CSS v4 and `@llm-market-bench/ui-design-system`.

## Auth / DB client separation

The web app uses two strictly separated Supabase client families (see [[concepts/auth-db-client-separation]]):

- **Auth client** — `apps/web/src/lib/auth.ts` (`getAuthServerClient`) and `apps/web/src/lib/auth-client.ts` (`getAuthBrowserClient`) talk to **Supabase Cloud** for password login, Google OAuth, session cookies, and `auth.getUser()`. `assertValidAuthUrl` rejects any URL containing `benchify-archive-db` to prevent `PGRST125` auth misrouting. `getAuthServerClient()` resolves its URL/key from `SUPABASE_AUTH_URL` / `SUPABASE_AUTH_ANON_KEY`, falling back through `SUPABASE_URL` / `SUPABASE_ANON_KEY` and then the `VITE_SUPABASE_AUTH_*` / `VITE_SUPABASE_*` build-time variables.
- **DB client** — `apps/web/src/lib/db.ts` (`getDbServerClient`, `getDbAdminClient`, `getDbBrowserClient`) talks to the **self-hosted PostgREST archive DB** (`https://benchify-archive-db.clvg.uk`) for all data reads/writes, using stateless `createClient` options (`persistSession: false`, `autoRefreshToken: false`, `detectSessionInUrl: false`). `getDbAdminClient()` is an explicit dedicated export used for privileged server-side operations (chat schema introspection, `chat_memories` writes, `agent_chat_queue` audience submissions, and Recipe Studio recipe/queue/alert/waitlist writes) to prevent bundler parameter folding optimizations from dead-code eliminating service_role branches.

All feature data fetchers import `getDbServerClient` / `getDbBrowserClient` from `~/lib/db`; auth routes import `getAuthServerClient` from `~/lib/auth`. The former `~/lib/supabase` and `~/lib/supabase-client` modules have been removed.

### Auth resilience in the root route

`fetchUser` (the root route's `createServerFn`) wraps `auth.getUser()` in a `try/catch` and returns `null` (guest) on any thrown error, missing user, or missing email, logging a `console.warn` rather than propagating. `RootDocument` reads the route context defensively (`context?.user`) so it renders safely even when the router is in an error state and the context is undefined. Together these keep a transient Auth-service failure from crashing the root route — the app degrades to an unauthenticated render instead.
