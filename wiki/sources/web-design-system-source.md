# Source: Web Design System

Synthesized from `raw/docs/web/DESIGN_SYSTEM.md`.

## Takeaways

- **"Bloomberg Terminal meets Wired"**: Aesthetics prioritize data density and readability with a distinctive "cyberpunk-lite" color palette (Neon Green, Electric Blue, Alert Red).
- **Simplicity Over Abstraction**: Prefers direct mapping of props to Tailwind classes rather than complex token layers, ensuring the build output is predictable and easy to debug.
- **Fluid Layouts**: Uses a homegrown system of primitives (Stack, Cluster, Grid) to handle responsiveness with minimal size-specific utility prefixes.
- **Accessibility First**: Maintains WCAG AA contrast ratios and respects `prefers-reduced-motion` settings.
